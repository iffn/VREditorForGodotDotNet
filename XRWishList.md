# XR Whishlist
About https://github.com/GodotVR/godot-xr-tools

- `XRToolsViewport2DIn3D` should not override `@export` variables assigned in the UI.  
https://github.com/GodotVR/godot-xr-tools/issues/889

- `XRToolsMovementProvider` should have a `on_enable` and `on_disable` call when `enabled` is swapped.

- There should be a simple gravity flag or a vector on the player controller.

- Things like the width of the `XRToolsFunctionPointer` should scale with the player scale.

- The `class_name` and name of the file should be the same imo. The file of `XRToolsFunctionPointer` is called function_pointer for example.
